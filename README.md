# EAK International School — Multipage Website

Responsive frontend-only school website project created for the Modern School Website Redesign assignment.

## Pages
- `index.html` — Home
- `about.html` — School story, vision, mission and values
- `academics.html` — Primary, middle and senior learning stages
- `facilities.html` — Illustrative campus facilities
- `events.html` — Searchable and filterable notices/events
- `admissions.html` — Sample admission process, checklist and FAQs
- `contact.html` — Contact details and demo enquiry form

## Stack
HTML5, CSS3, vanilla JavaScript. No build step, framework, database or backend is required.

## Run
Open this folder in VS Code and launch `index.html` with Live Server, or open it directly in a browser. Google Fonts and the Unsplash images require internet access.

## Interactions
- Responsive navigation menu on mobile
- Event search and category filter
- Browser form validation and local demo confirmation
- Automatically updated footer year

## Design decisions to explain
- Forest green and lime create a calm, nature-inspired identity.
- Generous whitespace and clear headings help parents scan key information.
- Shared navigation, cards and spacing make all pages feel consistent.
- Plain HTML links allow each page to work without a framework.

## Limitations
EAK International School is fictional. Principal, dates, statistics, address, contact details and school information are placeholder content. Images are illustrative. The form does not send or store information. Replace or clearly label demo content before any real-world use.
